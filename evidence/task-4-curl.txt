DEFECT 4 (Validation): create_withdrawal failed to enforce MINIMUM_WITHDRAWAL_MINOR
--------------------------------------------------------------------------------
Description:
In create_withdrawal(), only ($amount > $available) was checked.
The code did not validate ($amount < self::MINIMUM_WITHDRAWAL_MINOR), allowing withdrawals below 50,000 minor units (500 NGN).
Per API-CONTRACT.md, amounts below the minimum must be rejected with 422 Unprocessable Entity and code 'below_minimum'.
